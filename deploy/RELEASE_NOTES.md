## Which variant do I need?
- If you have **Java >= 21** already installed (all OS): _jatos.zip_
- **Not Java >= 21** installed: Choose, according to your OS, between
    - _jatos_win_java.zip_
    - _jatos_mac_aarch64_java.zip_ (Apple Silicon Macs)
    - _jatos_mac_x64_java.zip_ (Intel-based Macs)
    - _jatos_linux_java.zip_
- If you prefer **Docker**: [hub.docker.com/r/jatos/jatos](https://hub.docker.com/r/jatos/jatos/tags?page=1)
